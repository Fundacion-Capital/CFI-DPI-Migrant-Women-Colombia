# Main-paper descriptive exhibits

The sample table selects age, grouped recorded residence and education from the audited academic descriptive run (WP07 R6). It omits occupation and does not add any cross-tabulations. The table draws on `sample_composition.csv` from the `descriptives` stage of the academic `2 Analysis.do`.

The onboarding artwork and its caption are unmodified outputs of that same Stata stage. Both enter the main paper together so the 404 complete-pair denominator and the 19 unscored records are visible with the chart.

The measurement summary selects the two valid-binary outcome rows from `engagement.csv` and the three own-base fixed scores from `scores.csv` (also displayed in `S3_score_coverage.tex`). It reports aggregate counts, shares, means and standard deviations from that same run; no estimates or raw inputs are regenerated.

These files contain aggregates only. Their use in the working draft does not settle institutional or repository release decisions.
