# Official command references checked for this source pass

Checked 8 November 2026. Source/manual review is not installed-version parsing.

- [StataCorp backslash and macro rules](https://www.stata.com/support/faqs/programming/backslashes-and-macros/): why literal doubled backslashes cannot be treated as emitted TeX row endings. The producer now writes explicit `\tabularnewline` commands.
- [File read/write](https://www.stata.com/manuals/pfile.pdf): direct text/numeric file output and owned file handles.
- [Numeric formats](https://www.stata.com/manuals/dformat.pdf): exponential audit format versus rounded display format; original ledger tokens remain separately preserved.
- [Destring](https://www.stata.com/manuals/ddestring.pdf): default double conversion, missing-token handling and numeric-key uniqueness after conversion.
- [Frame put](https://www.stata.com/manuals/dframeput.pdf): copying selected aggregate fields into new frames, without altering source frames.
- [Frame links](https://www.stata.com/manuals/dfrlink.pdf) and [frget](https://www.stata.com/manuals/dfrget.pdf): keyed aggregate linkage and copying N/metadata/variance cells.
- [Capped interval plots](https://www.stata.com/manuals/g-2graphtwowayrcap.pdf): horizontal range bars in the fixed two-panel comparison figure.
- [Logs](https://www.stata.com/manuals/rlog.pdf): named ordinary logs and read-only log inventory. Preserved installed-version evidence governs the literal `_all` spelling; PDF text extraction can drop its underscore.

No journal formatting rule or external methodological claim is adopted here.
