## Query from the repository root

The mutable, Git-ignored entrypoint is `graphify-out/`. Use these mirrors rather than running CLI operations inside the frozen audit packet. On this workstation the executable is `%USERPROFILE%\.local\bin\graphify.exe`.

```powershell
$env:GRAPHIFY_QUERY_LOG_DISABLE = '1'
graphify query "remittance digital inclusion" --budget 1800
graphify query "measurement eligibility version" --budget 1800
graphify query "latent class convergence" --dfs --budget 1800
graphify query "archive replication history" --graph "graphify-out/all_files_graph.json" --budget 1800
```

These exact vocabulary-constrained queries passed the native CLI, including BFS, DFS and the all-files view. Query traversal reads graph JSON; it is not authority to load participant data, execute Stata or fit a model. Line anchors refer to staged text projections, not necessarily Word page numbers or original Stata line numbers. Reopen the original source and its accepted provenance contract before making precise scientific or coding decisions. Ambiguous basename links do not resolve runtime macros or identify an authoritative exhibit.

The native benchmark estimated 1,074 context tokens per test query versus approximately 3,546,364 for a naive full-staged-text context (3,302x size ratio). This is only a heuristic: actual agent token usage, billing savings, latency and retrieval accuracy were not measured. Native zero-token fields are explicitly unavailable-usage placeholders.
