# Model readiness, inference and remaining decisions

This is a practical decision memo, not a request to repeat accepted construct
interviews. D2/D3 meanings, outcome priorities, conditional logit nomination,
reference labels, six-test family and conditional Holm policy remain accepted.
No participant counts, estimates, model ranks or standard errors were computed.

## 1. What the code can determine now

The source chain establishes the names and intended meanings of the two outcomes,
three focal candidates and proposed context fields. The codebook verifies
completed secondary=education 5, Bogotá=prepared residence 1, and employee/worker=
occupation 3. The new readiness file checks representations and reports prospective
nonmissing-input counts without changing a record, fitting or declaring model N.
It checks raw age/education/occupation/arrival domains as review counts, not
automatic exclusions. It neither computes candidate scores nor treats a raw
arrival year as an adopted tenure measure.

An eventual model-readiness record must additionally show, separately for R0,
D0, R1 and D1: admitted cohort continuity; outcome valid/missing and 0/1 support;
each component's applicability and ordinary/sentinel/unresolved states; covariate
domain validity; supported categorical/reference levels; complete valid joint
inputs; outcome-by-predictor support; and geography/version coverage. Mere
nonmissing counts are insufficient. Rank, separation, estimator omissions and
convergence are not known from source reading and cannot be certified now.

The full cohort is not dropped to a common complete-case sample. If a future
model uses fewer records because its specified fields are valid and observed,
that model-specific selection must be accounted for. Common-observation
definition comparisons are additional reports, not a silent replacement of
own-N descriptions. No sparse-cell collapse, imputation, penalized estimator,
new exclusion or extra fit is an automatic remedy.

## 2. Four equations: nominated, not frozen commands

For each outcome Y, the core linear predictor nominates three continuous
provisional candidates (IAT3, IADT2, IAFF2), age as a continuous term, categorical
education and version-aware categorical residence. The outcome-specific
coefficients and intercept are distinct. The logit link is the accepted
conditional starting model, not proof of suitability for the available support.

Extensions add nominal occupation and first-arrival calendar history only after
that history's exact representation/provenance is resolved. A calendar gap and
a raw year may relate algebraically under a fixed common reference year, but
this does not authorize choosing a clock, interpreting latest return or assuming
that reference year is common. IVS is not added beside its own constituents.
No ICDP-plus-IADT automatic joint model, interaction grid or every-item logit is
included in these four nominations.

No executable logit line is supplied with a missing VCE clause: omitting the
clause would silently select a software variance default. No margins call with
arbitrary score values or an unavailable reference category is supplied either.
These are explicit scientific implementation gaps, not syntax tasks to fill
with a fallback.

## 4. Multiplicity and uncertainty contract

The primary family has exactly six slots: IAT3, IADT2 and IAFF2, each in the
remittance main model and the domestic main model. Context adjustment terms,
extensions, candidate-definition comparisons and LCA profiles are not additional
primary discoveries. The accepted conditional Holm procedure follows Holm (1979).
For six valid ordered p-values, the sequential comparison uses denominators
6,5,4,3,2,1; adjusted p-values require the monotone step-down construction, not
six independent unadjusted decisions. This describes the method, not computed
test values or an implemented p-value routine.

Preserve all six planned slots if one is nonestimable. Do not shrink the family,
substitute a favourable extension, insert an invented p-value or describe an
incomplete adjustment as complete. The exact unavailable-test implementation
still requires an explicit pre-execution decision. Model-based pointwise 95%
intervals, raw p-values and adjusted p-values remain distinct reporting objects;
none exists in this package. A wide interval or nonsignificant result does not
prove no association. An adjusted p-value does not repair poor measurement,
selection, common-method reporting or an indefensible covariance estimate.

## 5. What would close the next empirical stage

First qualify the exact permitted no-fit route and obtain the current restricted
input/output/use scope. Run only its approved operations and preserve unsupported
and indeterminate findings. Candidate-score verification is a separate scope from
raw TARGET33 P1-P4. Then resolve the affected scientific choices and name every
fit/postestimation operation in a bounded manifest. Current no-execution authority
does not roll forward. C2 stays held independently of any source-only completion.
