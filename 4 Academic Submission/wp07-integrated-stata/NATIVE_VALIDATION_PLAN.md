# Package E native validation handoff — not an execution grant

This is the finite check plan produced by A.6. It contains no observed counts or
test results. Use Stata MCP only, after a current explicit scope, source hashes,
restricted carrier/output identity and access/retention conditions are bound.
No worker implementation, Python analysis, alternative carrier, retry search or
shared-settings change is a step in this plan. An unavailable tool limits the
numerical stage, not permissible B/C/D/G manuscript work.

A future participant run requires a dedicated restricted Stata-MCP session and
no unrelated ordinary, command or unsafe transport logs. An empty dataset and a
named restricted log alone do not establish that isolation. Verify it within
E.1's actual authorized route; this source package qualifies no live session.

## Separate scopes

1. **E.1 — bind operations:** preserve the exact historical carrier seal, the
   source hashes and distinct raw versus prepared field sets. The existing
   163-field raw P1-P4 no-fit/no-scoring contract is not permission to execute
   the new 98-field academic master, compute scores or inspect other fields.
2. **E.2 — raw checks only:** when authorized, execute the applicable raw
   membership/version/route/time/geography operations and restricted aggregates.
   Preserve manual exclusions and the historical clock discrepancy. No score
   construction, fitting or eligibility recertification.
3. **E.3 — prepared scope:** separately authorize the declared constructions and
   93-item coverage checks on the bound carrier; reconcile candidate formulas,
   component/own/common N, raw answers, row continuity and model-input support.
   This is not model fitting. Do not silently enlarge the scope to identifiers,
   network reconstruction or respondent-level exports.
4. **E.4 — only later:** resolve the stated inference/contrast/calendar conditions
   and name every fit and postestimation operation before estimation. No E.4
   operation, p-value, Holm calculation or LCA fit is authorized here.

Each actual operation must report performed/not performed/technical stop rather
than manufacture an expected zero, N or coefficient. Stop for source/field/type
identity failure, an exhausted scope or an unapproved participant output. Preserve
the attempt; do not replace an input, strip a sentinel or retry under this plan.
