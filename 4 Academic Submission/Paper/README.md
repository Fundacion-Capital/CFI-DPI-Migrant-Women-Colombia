- **Bibliography:** In Zotero, export **Fundacion Capital → CFI DPI Migrant Women Colombia** as UTF-8 BibTeX to `bibliography/zotero-collection.bib` with Export Files and Export Notes unchecked. - **Build:** From this directory, run pdfLaTeX, BibTeX, then pdfLaTeX twice on `main.tex` (use `-no-shell-escape` with pdfLaTeX). Build `technical-supplement.tex` twice with pdfLaTeX. Send build artifacts to a scratch directory when validating. The repository-root `paper.tex` entry point additionally needs `BIBINPUTS` set to this folder's `bibliography/` directory, because classic BibTeX does not accept database names containing spaces. The root `supplement.tex` needs no BibTeX.
- **Overleaf:** The project compiles reviewed source snapshots, not the live local tree. Make manuscript changes here; send only the agreed manuscript and supplement snapshot for the next approved Overleaf update. Do not upload the raw Zotero export, internal packets, generated logs or restricted outputs.
- **Git:** The repository-root ignore rule covers this entire working directory, including the `Paper/` and `Presentations/` subdirectories. It does not remove any already tracked entry from the index or from existing commits. Do not stage or push working-paper files or internal packets.
