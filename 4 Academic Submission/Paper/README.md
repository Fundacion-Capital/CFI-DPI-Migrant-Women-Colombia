# Academic working paper

This is the first assembled TeX draft and separate supplement, not a submission or replacement for the academic audit record. Start with the [article](article.tex), [technical supplement](technical-supplement.tex) and [unsent Angélica review packet](COAUTHOR_REVIEW.md). The article is intentionally name-free in this working layout; an author/title-page file and exact declarations will be prepared at submission review. Names alone do not make a package anonymous.

- Substantive article text lives in `sections/`; supplement text lives in `supplement/`. One preamble and one keyed reference list serve the article. Keep references checked against source; APA-informed author–date is the working style, not a claim of exact journal compliance.
- From the repository root, the new `paper.tex` and `supplement.tex` are independent pdfLaTeX launchers. Build twice with `pdflatex -no-shell-escape`, directing all outputs outside the Git checkout. The source files also build directly from this directory. Do not change the existing `4 Academic Submission/main.tex` or the live Overleaf project. After approval, choose a root launcher as Overleaf's Main document only on the agreed project and branch. This follows the root-entry layout principle in [Overleaf's documentation](https://docs.overleaf.com/getting-started/recompiling-your-project/the-main-document); it uses native input paths rather than requiring an extra package.
- The [mixed-evidence source review](../wp07-mixed-benchmark-integration/REVIEW.md) governs the legacy anchors, fixed exhibit slots, replacement captions, and five-country claims. The [methods package](../wp07-academic-methods-package/METHODS_DRAFT.md), [item register](../wp07-integrated-closure/ITEM_EXHIBIT_MAP.csv), [held descriptive source handoff](../wp07-source-advance/EXHIBITS.md) and [E.5 acceptance checks](../wp07-e5-v3-restricted-render-contract/ACCEPTANCE.md) govern quantitative denominators and eventual displays. Earlier methods prose is not a substitute for the later exact E.4/E.5 specification.
- The [WP05 source ledger](../wp05-literature-context/SOURCE_LEDGER.csv) and [Colombia chronology](../wp05-literature-context/COLOMBIA_DPI_CHRONOLOGY.md) remain the broader bibliography and setting handoff. This assembly adds a focused contextual comparison with Eaves and Rao and Cirolia et al.; it does not claim every Zotero/NotebookLM source was reread or every historical citation adopted. Keep the original legislative, news and benchmark references preserved.
- Do not add placeholder files that pretend to contain results. The article and supplement render labelled text slots until separately accepted outputs exist. The [narrowed R04 route](../wp06-institutional-rights-review/R04_ACCEPTED_NARROWED_ROUTE_2026-10-24.md) and [R12 account](../wp06-institutional-rights-review/R12_ACCEPTED_DOCUMENTARY_ACCOUNT_2026-10-25.md) do not authorize release or final ethics wording.
