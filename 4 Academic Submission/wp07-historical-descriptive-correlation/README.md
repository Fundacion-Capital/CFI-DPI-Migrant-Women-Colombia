1. Revalidate byte identity, permitted access, exact case-sensitive fields and
   numeric types, expected row count and applicable runtime settings before
   dispatch. Use the restricted archived file only; no public-tree copy,
   latest-file search, backup input, new recode, selected subsample, or
   inferred cross-carrier identity. Stop on any mismatch.
2. Prepare an exact aggregate-only Stata MCP selection and capture schema
   for **one named block at a time**, in a fresh owned session. The existing
   drafts print diagnostics and are not exact-precision export adapters.
   Bind the source, command boundaries, working directory, run limits,
   output destination, named readers and retention before seeking a grant.
   Do not use the TARGET33 or V6 trial authority for this scope.
3. Compare integer counts, keys, dimensions and applicable flags exactly.
   For a CSV compare underlying numeric results to the retained decimal
   tokens under an explicitly pinned per-field precision contract; do not
   infer storage precision from Stata formats or rounded Markdown. For F5
   inspect typed workbook cells before binding numerical tolerance; compare
   pair keys first and preserve the original sorting as a separate display
   check. No rounding tolerance is granted here except the already frozen
   diagnostic bounds inherited for block 08. An absent reference is
   unavailable, never an automatic match.
4. Record runtime and exact input identity, before/after data signatures,
   sample and denominator evidence, expected versus observed aggregate cells,
   and the terminal/cleanup receipts. No respondent key, record, raw text,
   contact field, posterior or row-level export. On any failure stop, preserve
   partial evidence, and do not retry or expand scope without authorization.
   Label output as exact match, precision-limited compatibility, mismatch,
   or not testable. None establishes causal validity, disclosure clearance,
   or approval to replace any original.
