## Native Stata implementation
The code uses direct commands and ordinary statistical loops, without helper
programs, plugin installations, generic model frameworks or alternate estimators.
The five literal commands match the adopted manifest, including reference groups,
conditional robust covariance and original arrival-year extensions. All three
entry holds remain, and a second `exit 198` protects the estimation boundary.

Model-specific inclusion preserves the admitted cohort and source answers.
Known categorical support failures block the affected named model without a fit.
After a fit, exact e(sample), convergence, expected rank (present levels only),
finite native coefficients/covariance, positive focal SEs and nonzero perfect-
predictor rules govern disposition. Native determined-success/failure counts
are retained as diagnostics, **not a new automatic rejection threshold**:
Stata documents that they can reflect very small predicted probabilities.
This reviewer-identified over-broad draft condition was removed before handoff.
[Stata logit manual, technical note and stored results](https://www.stata.com/manuals/rlogit.pdf).

Six coefficient-null tests belong only to the two core models. Raw p-values
are copied at 17-digit precision before other returned results can replace them.
The temporary results frame contains only those six aggregate hypothesis
records; it never contains participants. Missing slots stay missing under fixed-
six Holm. Pointwise probability intervals are not Holm simultaneous intervals.

Exact endpoint counts are recorded before fitting. Unavailable endpoints leave
only their probability comparison unavailable. Each available margins operation
restores its stored model, copies the full declared native matrix returns,
checks layout/estimability and verifies higher-minus-lower direction. Unknown
matrix layout is retained as an unavailable reporting object, not guessed.
Numeric probabilities remain in probability units; differences/SEs/limits are
converted together to percentage points. Delta interval bounds are not clipped.
[Stata margins/pwcompare](https://www.stata.com/manuals/rmarginspwcompare.pdf).

Working robust VCE still does not account for unrecorded referral or household
dependence. Neither successful code integration nor later artificial success
will establish that assumption, real grouped support or scientific fitness.
