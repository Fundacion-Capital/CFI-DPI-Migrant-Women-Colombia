## Sheet: methodological_rules

| rule_id | rule_area | rule_text |
| --- | --- | --- |
| 1 | No double counting | Do not include an index and the direct survey items used to construct that same index in the same LCA model. |
| 2 | Categorical LCA preference | For the main LCA, prefer ordered categorical versions of the indices rather than raw continuous scores. |
| 3 | Continuous scores | Continuous scores are retained for diagnostics, threshold validation, robustness checks, and post-LCA cluster profiling. |
| 4 | Auxiliary variables | Direct survey items listed as auxiliary variables should be used mainly to interpret and validate the clusters after model estimation. |
| 5 | Redundancy checks | Highly overlapping constructs should not be forced into the same main model unless diagnostics show they add distinct information. |
| 6 | Interpretability | Final model selection should balance fit statistics, classification quality, minimum class size, stability, and substantive interpretability. |
