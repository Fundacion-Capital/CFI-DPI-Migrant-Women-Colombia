## The three scripts

- **0 Master.do:** one exact historical admitted carrier, a literal 98-field
  research projection, one preparation call and one analysis call. Paths are
  three explicit arguments: repository, restricted archive root, restricted
  output directory. No username branches, installation, alternative carrier,
  Python integration, globals or old-master fallback.
- **1 Data preparation.do:** preserves raw answers and rows; classifies all
  93 source items across fifteen domains using the accepted version/route rules;
  constructs only the eleven declared provisional summaries and distinct
  engagement fields. Six response states remain visible in named variables.
- **2 Analysis.do:** explicit item/option denominators, fixed-component and
  common-observation summaries, prospective model-input support screens and the
  declared IAT/IADT descriptive associations. Resolved model terms are documented;
  unresolved inference, calendar and LCA choices are not executable defaults.

The named route/state variables are reporting masks, not new substantive scales.
Long repeated multiselect-validity expressions are written once as visible
Boolean checks, not helper programs. Source answers are never repaired.
State 5 retains item-specific sentinel meanings; state 6 is a review condition,
not a new exclusion. The offered uncertainty code 98 remains in domestic operation
bins, separate from the five substantive bins.

Fixed candidate arithmetic requires every declared scorable component. There is
no `rowmean`, zero-fill, automatic replacement composite, arbitrary cutoff or
new sample-wide normalization. Item states gate components consistently; the
previous short preparation draft did not fully check duplicate account options.
This accepted-rule alignment can change prospective coverage, not source answers.

The conditional R0/D0/R1/D1 terms, six primary test slots and nineteen comparison
handoffs are maintained. No covariance, unsupported probability contrast,
calendar representation, unavailable-test policy or LCA choice is silently made.
No historical H1/k4, hard-class regression grid, old all-index correlation matrix
or statistical result is promoted into the academic path.
