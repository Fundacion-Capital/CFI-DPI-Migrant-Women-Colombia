## What is revised

The complete historical section is retained as **one shared-scope do-file**.
Stage bookmarks and concise cautions expose the input, candidate, assignment
and downstream dependencies. Nineteen specifically recorded comment lines
were revised to distinguish intended sparsity reduction from demonstrated
local independence, historical preference from academic adoption, plot direction
from verified protection, and same-survey comparisons from external validation.

Blank-line clutter was reduced. No executable scientific command changed;
there were no remaining `reg` abbreviations requiring expansion in this
source window. All original programs, loops, captures, fallback branches,
macros, delimiters, braces, seeds, sorting, thresholds, labels, samples,
storage types and writer commands remain historical. No new Stata helper,
retry mechanism, error framework or automatic input choice was added.

This is **not** the final lean academic production pipeline. Simplifying or
replacing legacy helpers and fallbacks requires a distinct behavior-verified
revision. The historical commands remain visible so a reader can audit them
without losing their original state dependencies.

  labels nor posterior columns may automatically transfer to another fit.
- Artificial arithmetic demonstrates tie-priority and second-best-posterior
  limitations. No participant tie count or empirical effect is known from
  this review, and no assignment or margin has been corrected.
- Posterior weighting supplies descriptive summaries; the modal-class OLS,
  ANOVA, multinomial/logit and pairwise tests still have classification and
  dependence limitations. No automatic BCH/three-step replacement is supplied.

  routes. They cannot all be independent validation evidence.

  input/ID paths. All remain behind the stop. There is no fresh input
